# AI-секретарь госоргана

> Репозиторий команды **Krias-rep3** · репетиция хакатона BAITC

Агент принимает обращение гражданина, классифицирует его, находит основания
в регламенте и готовит черновик ответа на русском и казахском языках.
Каждый шаг агента пишется в JSON-трассировку.

## Что делает

1. **Классификация обращения** — `справка` / `жалоба` / `запись`.
2. **Поиск оснований** — из регламента (`data/reglament.md`) достаются
   3 наиболее релевантных пункта с указанием номера.
3. **Черновик ответа** — двуязычный (ru / kk), со ссылками на найденные пункты.
4. **Трассировка** — все шаги, вызовы инструментов и их результаты
   сохраняются в `logs/agent_log.json`.

## Архитектура

```
обращение
   │
   ▼
[classify]  ──► тип обращения + уверенность
   │
   ▼
[retrieve]  ──► 3 пункта регламента (embeddings + косинусная близость)
   │
   ├─ если тип = "запись" ──► [book_appointment]  (инструмент бронирования)
   │
   ▼
[draft_ru] ──► [translate_kk]
   │
   ▼
черновик ответа + logs/agent_log.json
```

Агент строится на tool-calling: модель сама решает, какие инструменты
вызвать, а оркестратор фиксирует каждый шаг.

## Стек

| Слой | Технология |
|------|-----------|
| Язык | Python 3.11 |
| LLM | OpenAI-совместимый API (провайдер переключается конфигом) |
| Поиск | sentence-transformers (BGE-m3) + косинусная близость |
| API | FastAPI |
| Тесты | pytest |

## Структура репозитория

```
.
├── agent/
│   ├── classify.py        классификация обращения
│   ├── retrieve.py        поиск пунктов регламента
│   ├── draft.py           генерация черновика ru/kk
│   ├── tools.py           инструменты агента
│   └── trace.py           запись шагов в JSON
├── data/
│   ├── reglament.md       вымышленный регламент
│   └── samples.json       примеры обращений
├── logs/
│   └── agent_log.json     трассировка последнего запуска
├── api.py                 FastAPI-эндпоинт
└── main.py                запуск из командной строки
```

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # указать ключ и адрес LLM-провайдера
python main.py --text "Прошу выдать справку о составе семьи"
```

Результат печатается в консоль, трассировка — в `logs/agent_log.json`.

## Пример трассировки

```json
{
  "request_id": "b3f1a2",
  "input": "Прошу выдать справку о составе семьи",
  "steps": [
    {"step": 1, "action": "classify", "output": {"type": "справка", "confidence": 0.94}},
    {"step": 2, "action": "retrieve", "output": {"clauses": ["3.1", "3.4", "7.2"]}},
    {"step": 3, "action": "draft_ru", "output": {"chars": 812}},
    {"step": 4, "action": "translate_kk", "output": {"chars": 794}}
  ],
  "duration_ms": 4310
}
```
